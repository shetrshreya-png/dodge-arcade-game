# 🎮 DODGE!

A 30-second browser arcade game where the goal is simple: **survive, dodge, and reach 750.**

🔗 **Live Demo:** https://dodgearcade.netlify.app

## 💡 How It Started

DODGE! started as a small experiment to understand how **QR codes could connect a physical interaction to a web experience**.

Instead of stopping at a simple QR → website demo, I decided to make the website interactive and turned the idea into a browser game.

That small experiment eventually became a project where I could explore JavaScript game mechanics, responsive controls, Supabase, and deployment.

## 🕹️ Features

- 30-second gameplay
- Keyboard and mobile touch controls
- Falling obstacles and moving barriers
- Increasing difficulty
- Multiple-obstacle waves
- Collision detection
- Combo multiplier system
- Score based on survival time
- Maximum score of **750**
- Personal Best stored locally
- Game Over reactions based on performance
- Online leaderboard using Supabase
- Unique player nicknames
- Top 10 leaderboard
- Responsive design for desktop and mobile

## 🛠️ Tech Stack

- **HTML**
- **CSS**
- **JavaScript**
- **Supabase**
- **Netlify**
- **QR Code**

## 🎯 Scoring

The game lasts 30 seconds.

The score increases based on survival time, with a combo multiplier that increases as the round progresses.

Survive the full 30 seconds to reach:

**750 points**

## 🏆 Leaderboard

DODGE! uses **Supabase** to store completed-round scores and display a live leaderboard.

Each nickname can have one leaderboard entry representing its first completed round.

## 📱 Play the Game

Open the game on your phone or laptop:

**https://dodgearcade.netlify.app**

You can also access the game through the QR code used for the project.
